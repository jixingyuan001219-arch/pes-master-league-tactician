# 疑难解答（FAQ）

## 1. 找不到存档在哪？

路径表见《数据读取指南》第一节。优先检查：`文档` 文件夹 → `KONAMI` → 版本名 → 数字ID → `save`。

最快方法：用 Everything（voidtools.com）等工具全盘搜索 `ML00000000`，一秒定位。

## 2. KONAMI 文件夹存在但里面没有存档？

- **Steam 云同步**：存档可能在云端，进游戏「设置 → 存档管理」确认本地是否生成；
- **换过 Windows 账户 / 重装过系统**：存档跟着旧用户目录走，去 `C:\Users\<旧用户名>\Documents` 找；
- **非 Steam 版**（EPIC / 主机版）：路径不同，本指南以 Steam 版为准；
- **Lite 免费版**：不提供大师联赛模式，自然没有 ML 存档。

## 3. save 目录里有多个数字文件夹？

数字是 Steam 用户 ID。一台电脑多人共号/多账号时每组 ID 一个文件夹；认准**最近修改时间最新**的那个。

## 4. dump 出来有「未找到」的球员？

球员 ID 恰好为 **2147483648（即 2³¹）** 说明名字库没匹配上——这多半是大师联赛的**青训/重生球员**，名字库没有收录。这不是数据损坏；更新名字库或单独手动标注即可。

## 5. 门将能力读不到？

16 项通用能力**不含门将专属能力**（扑救/反应/接球/覆盖范围），所以门将强弱无法从通用能力判断。两个办法：游戏内看门将总评；或单独抓门将专属能力的内存地址。

## 6. 总评（Overall）读不到？

总评是游戏按球员主位置**加权实时计算**出来的，不存进任何球员记录字段，内存里没有精确值。直接用 16 项能力判断强弱反而更精确。

## 7. 梅西才 16 岁、布冯 28 岁？

这是大师联赛的**转生机制**：名将退役后会以年轻形态重生，能力从低重新练。年龄小 = 潜力满级，不是 bug，而且转生小将是本工作流最该重点练级的对象。

## 8. 网页看板打开乱码 / 阵型错位 / 球员挤在球场顶部？

- **乱码**：文件是 UTF-8 编码，用现代浏览器（Edge/Chrome/Firefox）打开，别用老 IE；
- **球员全挤在顶部**：检查 HTML 里球员数据中练级标记是否写成了 `y:1`——`y` 是球场纵向坐标，练级标记必须用 `yng`（两者重名是历史 bug，会导致 B/C/D 队球员纵向坐标被覆盖成 1%）；
- **只改了数据但图不动**：确认浏览器缓存，Ctrl+F5 强刷。

## 9. 读出的能力值和游戏里显示的不一样？

正常。内存里是**含训练加成与状态波动的实时值**，游戏面板显示的是基础值。以内存值为准做分析。

## 10. 我有多个大师联赛存档，怎么处理？

一个存档 = 一份 CSV = 一套看板，输出到不同目录即可。本工作流不合并多档。

## 11. 可以用在线模式（myClub 等）的数据吗？

不推荐。本工作流只做**单机存档的只读解析与战术建议**，与在线对战无关；也请不要把内存读取工具用于在线模式。

## 12. 网页看板能不能放手机上？

可以。浏览器打开后直接截图存 PNG；或把 HTML 文件放到任何支持本地文件的设备/网盘里用浏览器打开（无需服务器）。

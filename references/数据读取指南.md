# 数据读取指南

本工作流需要两类数据：**存档导出**（球队背景，可选）和**实时能力值 CSV**（分析核心，必需）。

---

## 一、存档在哪（按版本找）

| 游戏版本 | 存档路径 |
|---|---|
| PES 2021 SEASON UPDATE（Steam） | `文档\KONAMI\eFootball PES 2021 SEASON UPDATE\<数字ID>\save\` |
| PES 2021（Steam 原版） | `文档\KONAMI\eFootball PES 2021\<数字ID>\save\` |
| PES 2020（Steam） | `文档\KONAMI\eFootball PES 2020\<数字ID>\save\` |

- `<数字ID>` 是 Steam 账号/产品相关的一串数字，每台电脑、每个账号不同；同目录下可能出现多组数字文件夹，认准**最近修改时间最新**的那组。
- Windows 下完整路径示例：`C:\Users\你的用户名\Documents\KONAMI\eFootball PES 2021 SEASON UPDATE\76561198000000000\save\`
- 找不到？见《疑难解答》第 1-3 条。

## 二、存档文件类型

| 文件 | 含义 |
|---|---|
| `EDIT00000000` | 编辑数据（球员/球队/转会） |
| `ML00000000` | 大师联赛存档（第二个档为 ML00000001，以此类推） |
| `SYSTEM00000000` | 系统设置 |
| `REPLAY*` | 比赛回放 |

## 三、存档导出目录（如 ml/）

用存档解析工具导出后常见结构（本工作流**只做只读解析**，不修改存档）：

| 文件 | 内容 |
|---|---|
| `description.dat` | 明文：存档名、球队、联赛、存档日期、赛事 |
| `header.dat` | 二进制，尾部含游戏版本名（如 eFootball PES 2021 SEASON UPDATE） |
| `version.txt` | 存档版本串 |
| `encryptHeader.dat` | 加密头（二进制） |
| `data.dat` | 主数据（加密，体积大） |

> `data.dat` 为加密数据，直接解析需逆向工作；本工作流**不依赖**解密它——球队背景从 `description.dat` 读取，球员能力从内存抓取。

## 四、内存抓取实时能力值（核心数据来源）

**为什么抓内存**：大师联赛中球员有转生年龄 + 训练成长，实时能力值与游戏面板显示不完全一致；且总评（Overall）是加权实时计算值，不存储在球员记录中，内存里读不到。

通用流程（以 Cheat Engine 为例）：
1. 打开游戏，进入大师联赛「我的球队」界面
2. 用 Cheat Engine 附加游戏进程
3. 以某名球员的已知能力值（如速度）为基准反复搜索、变动数值再搜索，缩小到唯一地址
4. 找到该球员数据块后，同一球员的 16 项能力在内存中连续排布（具体偏移因版本而异，可按"相邻地址规律"批量读取）
5. 逐球员批量 dump，整理成 CSV

常见坑见《疑难解答》第 4-8 条。

## 五、CSV 格式契约

表头固定（第一行）：

```
球员ID,名字,年龄,进攻意识,控球,盘带,紧密控球,地面传球,高空传球,射门,头球,速度,加速,脚下力量,跳跃,身体接触,体力,防守意识,抢断
```

16 项能力含义：

| 字段 | 含义 | 谁最需要 |
|---|---|---|
| 进攻意识 | 前插、跑位、抢点 | 前锋/前腰 |
| 控球 | 接球与护球 | 中场/组织者 |
| 盘带 | 带球推进 | 边锋/前腰 |
| 紧密控球 | 狭小空间护球 | 组织者/内切型 |
| 地面传球 | 短传精度 | 中场 |
| 高空传球 | 长传/传中精度 | 出球中卫/边锋 |
| 射门 | 终结能力 | 中锋/前腰 |
| 头球 | 争顶与头球攻门 | 中锋/中卫 |
| 速度 | 冲刺速度 | 边锋/边卫 |
| 加速 | 起步爆发 | 前锋/边锋 |
| 脚下力量 | 远射/长传力量 | 中前卫/边卫 |
| 跳跃 | 争顶弹跳 | 中卫/门将 |
| 身体接触 | 对抗能力 | 中卫/后腰 |
| 体力 | 续航 | 全场跑动者 |
| 防守意识 | 防守站位 | 中卫/后腰 |
| 抢断 | 夺球能力 | 后腰/边卫 |

示例见 `examples/能力值示例.csv`（巴萨大师联赛真实数据）。

# PES 大师联赛 AI 主教练（Skill）

给你的**实况足球大师联赛**配一个 AI 主教练：读你的存档和球员数据，帮你**排阵容、定打法、练小将**，最后生成一张网页战术板——**每场赛前打开，照着摆就行**。

> 支持 PES 2021 / eFootball（实况足球），主打单机大师联赛模式。

## 它能帮你做什么

**📋 排阵容，不用再纠结**
每场比赛谁首发、替补席带谁、第几分钟换谁，全部安排得明明白白。对手强用主力，对手弱上轮换，一眼就能决定。

**🎯 定打法，一句话看懂**
4-3-3 快速反击怎么打？落后了变什么阵？领先后怎么守住？看板上一眼看到，照着执行。

**🌱 练小将，转生球员不浪费**
大师联赛里梅西、范戴克这些名将退役后会"转生"成 16 岁的小将重新成长。看板告诉你该给谁上场时间、怎么把潜力练回满级。

**🖥️ 网页战术板，双击就打开**
生成一个本地网页：今天踢联赛？点「联赛」页签；对手是弱队？切到轮换阵容那一页。照着在游戏里摆好就开踢，全程不用联网。

## 三分钟上手

1. **导一份球员数据**——一份 CSV 表格，包含每名球员的 16 项能力值（怎么导、存档在哪找，见 [`数据读取指南`](references/数据读取指南.md)）
2. **把数据发给 AI 助手**——Cherry Studio、Claude Code 等任何支持 Skill 的工具都行
3. **拿到网页战术板**——得到 `index.html`，双击用浏览器打开，每场赛前照着抄

## 战术板长什么样

打开是一张绿色球场图，11 名首发按真实站位摆好，每个人名字旁边标着他的看家本事（比如"速度 99"）。旁边清清楚楚写着：

- **这场怎么打**：进攻、防守、攻防转换各一句话
- **替补席带谁**：7 个名额都排好了
- **什么时候换人**：第 60、65、70 分钟分别换谁
- **打法要点**：底部常驻 3 条（比如"某球员体力差，打不满全场，70 分钟前必须换"）

# PES 大师联赛战术总监（Skill）

面向 **PES 2021 / eFootball 大师联赛**玩家的 AI 战术总监工作流：从存档与内存数据出发，一键生成「每场赛前照抄即可」的可视化战术看板。

## 能干什么

- **读取数据**：EDIT/ML 存档导出（球队背景）+ 内存抓取的 16 项实时球员能力值（含转生年龄与训练成长，比游戏面板值更真实）
- **人岗匹配**：按能力判断每名球员的最佳位置与角色
- **四层梯队**：A队主力 / B队轮换 / C队练级混编 / D队全练级，每层带阵型图、打法说明、替补席 7 人、换人顺序
- **阵型推导**：4-3-3 首选 + 4-2-3-1 / 3-5-2 备选，附选型逻辑
- **三线节奏**：联赛 / 欧冠 / 国王杯分别怎么用兵（按对手强弱、杯赛轮次切换）
- **可视化输出**：页签式 HTML 战术看板，本地双击即开、无需联网；底部常驻"铁律"栏

## 快速开始

1. **准备数据**：一份 16 项能力值 CSV（怎么拿见 [`references/数据读取指南.md`](references/数据读取指南.md)）
2. **交给 AI**：把 CSV 发给任何支持本 Skill 的 AI 助手（Cherry Studio / Claude Code 等）
3. **拿到看板**：得到 `index.html`，赛前流程变成——今天踢什么 → 点页签 → 看对手 → 点子页签选队 → 照抄阵容

## 工作流

```
EDIT 存档导出（球队背景）  +  内存抓取（实时能力值 CSV）
        │
        ▼
   数据校验（未找到球员 / 门将能力 / 总评缺失）
        │
        ▼
   战术分析（位置适配 → A/B/C/D 分层 → 阵型推导 → 铁律 → 换人）
        │
        ▼
   生成可视化看板（页签式 HTML）+ 可选文字手册
```
